Über REOS Content OS

Version 1.0.0

REOS Content OS ist ein KI-gestütztes Content-Management-System für die REOS Group. Es automatisiert die Recherche, Planung und Erstellung von Social-Media-Inhalten für den deutschen Immobilienmarkt.

  • Automatische News-Recherche via Claude + Web Search
  • KI-generierte Wochenpläne (6 Posts, Mo–Sa)
  • Detaillierte Design-Briefs für Canva
  • Post-Tracker mit Status-Management
